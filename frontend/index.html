MATHEMATICAL FOUNDATION

Formulas & Feature Extraction Methodology

1. Statistical Time-Domain Features

Extracted from raw vibration signal \(x = [x_1, x_2, \dots, x_N]\):

Root Mean Square (RMS): (Energy indicator) $$\text{RMS} = \sqrt{\frac{1}{N} \sum_{i=1}^N x_i^2}$$
Standard Deviation (\(\sigma\)): $$\sigma = \sqrt{\frac{1}{N - 1} \sum_{i=1}^N (x_i - \mu)^2}$$
Kurtosis (\(K\)): (Sensitive to early-stage transient shocks) $$K = \frac{\frac{1}{N} \sum_{i=1}^N (x_i - \mu)^4}{\sigma^4} - 3$$
Skewness (\(S\)): (Signal asymmetry) $$S = \frac{\frac{1}{N} \sum_{i=1}^N (x_i - \mu)^3}{\sigma^3}$$
Crest Factor (\(CF\)) & Shape Factor (\(SF\)): $$CF = \frac{x_{\text{peak}}}{\text{RMS}}, \quad SF = \frac{\text{RMS}}{\frac{1}{N}\sum_{i=1}^N |x_i|}$$

2. Normalization & Machine Learning Metrics

Standard Scaling (Z-Score Normalization): $$z = \frac{x - \mu_{\text{train}}}{\sigma_{\text{train}}}$$
Model Risk / Failure Probability: $$P(\text{Fault} \mid X) = \sigma(W^T z + b) = \frac{1}{1 + e^{-(W^T z + b)}}$$
Classification Performance Metrics: $$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$ $$\text{Precision} = \frac{TP}{TP + FP}, \quad \text{Recall} = \frac{TP}{TP + FN}$$ $$F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$
